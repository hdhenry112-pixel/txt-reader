# 真机检查清单

Playwright 的 WebKit 不等于 iPhone 上的 Safari。下面这些只能在真机上确认。
每项写「看到什么算通过」。不通过的把现象（最好带截图）发给 Claude。

## M0 骨架和部署链路（版本 0.1.0）

先按 `docs/DEPLOY.md` 第三节把 App 添加到主屏幕。

| # | 操作 | 通过标准 | 结果 |
|---|---|---|---|
| 1 | 从主屏幕点「阅读」图标 | 全屏打开，没有 Safari 的地址栏和底部工具栏 | |
| 2 | 看主屏幕图标 | 青绿色底、一页纸、右上角橙色书签；名称是「阅读」 | |
| 3 | 看页面内容 | 左上「书架」，中间「还没有书」，底部「版本 0.1.0」 | |
| 4 | 看屏幕最顶上的状态栏（时间、电量） | 黑底白字，时间和电量看得清；「书架」标题没有被刘海或状态栏挡住 | |
| 5 | 看屏幕最底下 | 「版本 0.1.0」没有被底部横条挡住 | |
| 6 | 在页面上双击；再用两指捏合 | 页面不放大也不缩小 | |
| 7 | 划掉 App → 开飞行模式 → 重新从主屏幕打开 | 照常显示书架和版本号，不是白屏，也不是「无法打开页面」 | |
| 8 | 页面背景色 | 偏暖的浅灰（#F2F1EC），不是纯白 | |

第 4 项如果状态栏不是黑底白字（比如文字看不清），告诉我实际的样子，三种写法我换着试。

「有新版本，点击刷新」的提示要等 M1 发布时才能在真机上验证，到时列在 M1 清单里。

## M1 导入、分章、书架（版本 0.1.1）

这一版书架上的书**还点不开**，阅读页在下一版（M2）。这一版只验证导入和书架。

| # | 操作 | 通过标准 | 结果 |
|---|---|---|---|
| 1 | 从主屏幕打开 App（要联网），等几秒；没反应就切到后台再切回来 | 底部出现绿色提示「有新版本，点击刷新」 | |
| 2 | 点这条提示 | 页面刷新，底部版本号从 0.1.0 变成 0.1.1，右上角出现「导入」按钮 | |
| 3 | 点「导入」 | 弹出 iOS 的文件选择界面（可能先出现「照片图库 / 拍照 / 选取文件」菜单，选「选取文件」） | |
| 4 | 在「我的 iPhone」或 iCloud 位置选一本 UTF-8 的 txt | 文件不是灰色、可以选中；回到 App 后书出现在书架上，显示书名和 0% | |
| 5 | 再点「导入」，切到 **Google Drive** 位置选一本 txt | 同上。**如果 Google Drive 里的 txt 是灰色选不了，告诉我**，这是 spec 里预先标过的风险 | |
| 6 | 一次选多本（文件选择界面右上角「选择」或长按多选） | 顶部依次显示「正在导入 1/3：书名」；结束后几本都在书架上 | |
| 7 | 选一本 GBK 编码的 txt（老的中文小说大多是） | 书名正常；书名下面**没有**橙色的「编码可能有误」 | |
| 8 | 把已经导入过的同一个文件再导入一次 | 弹出「导入结果」，写着「《书名》已在书架」；书架上没有多出一本 | |
| 9 | 导入一本你平时看的大书（几 MB 到几十 MB） | 能导入成功。**记一下大概花了几秒**告诉我 | |
| 10 | 点某本书右边的「删除」→ 先点「取消」→ 再点「删除」→「删除」 | 取消时书还在；确认后书从书架消失 | |
| 11 | 划掉 App → 开飞行模式 → 重新打开 | 书架上的书都还在 | |
| 12 | 导入几本之后看整体 | 书名长的能换行不被截断；「删除」按钮没有被挤出屏幕 | |

第 1 项如果一直不出现提示：确认手机联网，然后把 App 划掉重开一次。还不行就告诉我。
